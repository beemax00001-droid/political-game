# سایت «حرف بزنیم؟» 🎀

این پروژه یک سایت استاتیک و آماده‌ی انتشار با **GitHub Pages** است.

## انتشار روی GitHub
1. وارد GitHub شو و یک Repository جدید بساز.
2. فایل ZIP را از حالت فشرده خارج کن.
3. فایل‌های `index.html`، `style.css`، `script.js` و پوشه‌ی `assets` را در ریشه‌ی Repository آپلود کن.
4. از مسیر **Settings → Pages**، گزینه‌ی **Deploy from a branch** را انتخاب کن.
5. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و Save کن.
6. چند دقیقه بعد آدرس سایت در همان بخش نمایش داده می‌شود.

## تلگرام و ارسال نتیجه
دکمه‌ی پایانی، گفت‌وگوی `@beemax_1` را در تلگرام باز می‌کند و نتیجه را به شکل متن آماده در کادر پیام قرار می‌دهد. مخاطب باید دکمه‌ی ارسال را خودش بزند تا پیام ارسال شود.

**نکته‌ی فنی:** GitHub Pages فقط میزبانی استاتیک ارائه می‌کند؛ بنابراین نمی‌تواند بدون یک سرور امن و ربات تلگرام، پیام را بی‌واسطه به حساب شما بفرستد. توکن ربات را هرگز داخل `script.js` یا فایل‌های عمومی GitHub قرار نده.

## شخصی‌سازی
- آدرس مقصد تلگرام در `script.js` از لینک اشتراک‌گذاری عمومی استفاده می‌کند؛ مخاطب می‌تواند گفت‌وگوی مقصد را در تلگرام انتخاب کند.
- متن‌ها، رنگ‌ها و انیمیشن‌ها در `index.html` و `style.css` هستند.
- تصویر گربه‌ی ارسالی در `assets/cat-sticker.jpg` قرار دارد.

سایت واکنش‌گراست و برای کاهش حرکت‌های شدید، تنظیمات `prefers-reduced-motion` دستگاه را هم رعایت می‌کند.
